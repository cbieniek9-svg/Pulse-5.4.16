# Pulse / TGP Command Center — worker-trust full-app review

This is a production store system used by floor workers, managers, and TV/phone stations.
Treat findings as go/no-go for store trust. Prefer false positives over misses on Critical/High.

## Review depth
- Line-by-line on security, money, inventory, identity, concurrency, and deploy/boot paths.
- Do not soft-pedal issues that could show wrong numbers, unlock wrong access, corrupt SQLite, or leave the store API down.

## Critical focus areas (must be airtight)
1. **Auth & access** — PIN/login, sessions, roles, device pairing, PC admin PIN, tokenless denial, HTTPS LAN enforcement, privilege checks on every mutating route.
2. **Financial integrity** — receiving report, period close, freight/allocation, cost/margin sheets, reopen/lock rules, invoice/ref handling, anything that changes money or inventory cost.
3. **Data safety** — process lock / single-writer SQLite, migrations, backups, EOD, attach-or-serve desktop vs Windows service, wrong data-dir / ABI mismatch.
4. **Floor truth** — counts, shrink, markdown, special orders, kill dates, rhythm/tasks, TV/mobile sync payloads — workers act on what they see.
5. **Service reliability** — boot before login, /api/ready, restart_required, install/deploy scripts that can leave a store half-updated.

## What “pass” means
- No Critical issues that can cause wrong money, wrong access, data corruption, or silent dual-writers.
- Remaining Warning/Info items must be explicit and non-blocking for floor trust, or called out as must-fix before store use.
