--- Windows service (headless API — required) ---
The store PC must run the TGP Command Center Windows service so the API is alive before anyone
signs into Windows. Without it, Chromebook /rec bookmarks and phone/TV portals die after reboot.

What it does:
  • WinSW service "TGP Command Center" (id TGP-CommandCenter) runs server.cjs at boot
  • Listens on port 3001 — serves /, /rec, /financial, /reports, /settings, TV sync, mobile uplink
  • Survives reboot: phones and /rec work at the Windows lock screen (no .exe login required)
  • Desktop .exe is optional UI-only when the service already owns :3001

Install (once per PC, or after a broken service):
  1. Close the desktop .exe (frees port 3001)
  2. Double-click resources\app\service\INSTALL.cmd → Yes on UAC
  3. Wait for === SERVICE OK ===
  4. Confirm: services.msc → "TGP Command Center" = Running
  5. Confirm: http://127.0.0.1:3001/api/ready → "ok": true
  6. Reboot test: leave PC at lock screen; phone opens http://<store-pc-ip>:3001/ — login loads

More detail: service\README.txt | STORE_SERVICE_DEPLOY.txt | service\REBOOT_SMOKE.txt
