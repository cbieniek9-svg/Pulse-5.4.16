# TGP Board Toolbox — Staff Meeting

**Purpose:** Introduce the live task board, show how we use it every shift, and agree on floor rules so we're aligned.

| | |
|---|---|
| **Suggested length** | 20–30 minutes + 10 minutes Q&A |
| **Lead** | Manager or Premium Clerk (shift lead) |
| **Audience** | All floor staff — stock/float, REC, bakery, premium |

---

## Opening (2 min)

> Starting today, the board is our shared to-do list for the shift — not extra paperwork. If it's on **ACTIVE DIRECTIVES**, it's real work. When you finish it, tap **DONE**. The TV shows the same thing so everyone sees priorities.

---

## Part 1 — What You're Looking At (5 min)

### Where we work

| Where | What it's for |
|-------|----------------|
| **Phone/tablet → TGP Centre Store** (`/`) | Main board — tasks, expiry, orders, receiving |
| **TV on the floor** | Same info, read-only — map, tasks, Daily Direction, pulls |
| **Receiving tablet** (`/rec`) | Truck time-in, TGP pallets, time-out |
| **Expiry tablet** (`/markdown`) | Log dates on aisle walks |

### Login

1. Open **TGP Centre Store** on your device
2. Pick your name → enter PIN → **UNLOCK UPLINK**
3. Shift lead sets **ACTIVE PREMIUM / SHIFT LEAD** at start of shift

### Main screen — two columns

**Left — ACTIVE DIRECTIVES**

- Today's rhythm tasks (store walk, FIFO, zone walks, etc.)
- Recovery tasks from zone checks
- Assigned by name when schedule is loaded

**Right — everything else that moves**

- **Expiry** — PULL / WARN
- **OOS flags** — shelf holes
- **Customer orders** — from CS
- **Vendor deliveries** — time in/out

**Top bar — KPIs**

Grocery, freezer, hardware, staff count, PPH — receiving updates labor when asked.

---

## Part 2 — Start-of-Shift Routine (5 min)

### Shift lead (Premium/Manager) — every morning

1. **UNLOCK UPLINK** on the lead device
2. Set **ACTIVE PREMIUM / SHIFT LEAD** (who owns huddle + board today)
3. **LOAD DAILY RHYTHM** — puts today's scheduled tasks on the board
4. Confirm **Daily Direction** is on the TV (manager posts priorities / must-wins)
5. Quick huddle: *"Here's what's on the board today — check your name."*

### Everyone else

1. Log in
2. Find tasks with **your name**
3. Work top priorities first (**Urgent** / **High** before **Routine**)
4. Tap **DONE** when finished — don't leave it open if it's done

> **Key message:** The board only works if we **close tasks when we finish**. Open tasks look like unfinished work to the next person and on reports.

---

## Part 3 — Daily Rhythm Tasks (5 min)

These load automatically when shift lead taps **LOAD DAILY RHYTHM**:

| Task | Who it usually goes to |
|------|------------------------|
| Daily direction huddle | Shift lead |
| Store walk / zone walks | Shift lead |
| FIFO Audit | Person scheduled for those aisles |
| Level displays, freezer check, back stock, etc. | Stock/float (from schedule) |
| **TGP Order** (Sun / Tue / Thu) | REC + whole floor when clock is running |

**Non–order days** (Mon / Wed / Fri / Sat): more back-stock, DOTS, and display work.

**Order days:** **TGP Order** is **Urgent** — REC and receiving lead that flow.

**If your name isn't on a task:** tell shift lead — they can reassign. Don't grab someone else's task without checking.

---

## Part 4 — Live Demo Walkthrough (8 min)

*Do this on a phone and point at the TV.*

1. **Show a task card** — name, zone, priority, **DONE**
2. **Complete one task** — tap **DONE**, show it disappear
3. **Show expiry panel** — **WARN** (7-day) vs **PULL** (today)
   - WARN → **SOLD THROUGH** if we sold through
   - PULL → **PULL** when removed from shelf
4. **Show customer order** — CS sent it → floor sees it → **DONE** when handled
5. **Show receiving** — **TIME IN** → work truck → **TIME OUT**
   - TGP trucks: log pallets on **`/rec`** before time-out
6. **Show TV** — map lights up for urgent work; Daily Direction at top

---

## Part 5 — Who Can Do What (3 min)

| Action | Clerk | Premium / Shift lead | Manager |
|--------|:-----:|:--------------------:|:-------:|
| Complete own tasks (**DONE**) | ✓ | ✓ | ✓ |
| Create / reassign / delete tasks | — | ✓ | ✓ |
| Load Daily Rhythm | — | ✓ | ✓ |
| Set shift lead | — | ✓ | ✓ |
| Receiving time-in/out | If permitted | ✓ | ✓ |
| EOD / reports / settings | — | Some | ✓ |

**Rule of thumb:** Clerks **work and close** tasks. Shift lead **loads rhythm, assigns, and keeps the board accurate**.

---

## Part 6 — Common Mistakes to Avoid (3 min)

1. **Not loading rhythm** → empty board; looks like nothing to do
2. **Leaving finished tasks open** → double work, bad stats
3. **Wrong person on a task** → tell shift lead; don't silently ignore
4. **TGP time-out without logging pallets on `/rec`** → blocked until pallets are logged
5. **Ignoring 7-day WARN** → use **SOLD THROUGH** if sold out
6. **Clerk trying to reassign tasks** → ask shift lead instead
7. **Multiple people on one login** → use your own name so assignments make sense

---

## Part 7 — Floor Agreements (2 min)

Ask the team to agree out loud:

- [ ] Shift lead loads rhythm **before huddle** (target: by **6:30**)
- [ ] Everyone checks the board **after huddle** and at **mid-shift**
- [ ] **DONE** means done — not *"I'll finish later"*
- [ ] Receiving uses **`/rec`** for TGP pallets every time
- [ ] Expiry walks use **`/markdown`** tablet; pulls show on the board
- [ ] Questions → shift lead first, manager second

---

## Q&A — Quick Answers

| Question | Answer |
|----------|--------|
| Where do I see my tasks? | **ACTIVE DIRECTIVES** — your name on the card |
| What if I'm not scheduled but I'm here? | Shift lead reassigns manually |
| What if the board looks doubled or wrong? | Tell manager **before** clearing anything |
| Do I need the app all day? | Check at huddle, mid-shift, and when the TV shows something new |
| What's the TV for? | Everyone sees priorities — you don't touch the TV |

---

## Closing (1 min)

> The board is how we stay aligned without chasing each other around the store. Load it, work it, close it. If something's wrong on the screen, speak up — we're still tuning this together.
