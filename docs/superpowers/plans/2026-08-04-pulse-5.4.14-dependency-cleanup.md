# Pulse 5.4.14 Dependency Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Pulse 5.4.14 with community `xlsx@0.18.5` removed, hybrid ExcelJS + BIFF spreadsheet reads, and multer 2.x for investigation attachments.

**Architecture:** One `spreadsheet-read` adapter detects `.xlsx`/`.xls`, parses via ExcelJS or `xls-reader`, and exposes sheet→objects + Excel serial date helpers. All former `require('xlsx')` call sites migrate to the adapter; ExcelJS writes stay unchanged. Multer upgrades independently with attach regressions.

**Tech Stack:** CommonJS Node/Electron, exceljs, xls-reader (spike-confirmed), multer 2.x, Node test runner.

**Workspace note:** Non-git deploy tree. Treat “Commit” steps as review checkpoints; no git commits unless the user asks.

**Spec:** `docs/superpowers/specs/2026-08-04-pulse-5.4.14-dependency-cleanup-design.md`
