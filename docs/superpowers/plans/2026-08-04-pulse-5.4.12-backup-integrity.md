# Pulse 5.4.12 Backup Integrity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Pulse 5.4.12 with verified backup packages, dual EOD backups, honest historical reports, fail-closed migration snapshots, and complete sidecar coverage.

**Architecture:** One `backup-package` pipeline creates consistent ops copies via better-sqlite3 `backup()`, verifies them, bundles inventory/attachments/transfers + manifest, and is the only success path for health, EOD, download, history export, and migration snapshots. Reports refuse missing/corrupt backups instead of falling back to live data.

**Tech Stack:** CommonJS Node/Electron, better-sqlite3, Express, Node test runner, Playwright where useful.

**Workspace note:** This tree is often non-git. Treat “Commit” steps as review checkpoints; do not create git commits unless the user explicitly asks.

function upsertSetting(db, name, value) {

function getBackupHealth(backupsDir) {

function openReportsTarget(db, backupFile) {
  if (!backupFile) return { ok: true, targetDb: db, close: () => {}, reportSource: 'live' };
  const bPath = resolveBackupPath(safeFile);
  if (!fs.existsSync(bPath)) {
    return { ok: false, code: 'BACKUP_SOURCE_UNAVAILABLE', error: 'Backup file not found.', targetDb: null, close: () => {} };
  }
  const verified = inspectBackupDatabase(bPath, { skipIntegrityCheck: true });
  if (!verified.ok) {

  }
  // open readonly wrapper...
  return { ok: true, targetDb, close, reportSource: 'backup', backupFile: safeFile };
}
